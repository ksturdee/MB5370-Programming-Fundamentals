# MB5370 Programming Fundamentals
 
This repository contains coursework, workshop activities, and practical exercises completed for MB5370 Techniques in Marine Science 1 at James Cook University.
 
## About This Repository
 
This module introduced the foundations of scientific programming, reproducible research, data visualisation, version control, and AI-assisted coding workflows.
 
The repository documents my learning and progress through the Programming Fundamentals module, including R scripts, Quarto reports, data visualisations, and GitHub workflows.
 
## Learning Outcomes
 
Through this module I am developing skills in:
 
- R Programming
- RStudio Workflows
- Git and GitHub
- Quarto Reporting
- Data Visualisation with ggplot2
- Reproducible Research
- Scientific Workflow Design
- AI-Assisted Programming
- Functional Programming with purrr
